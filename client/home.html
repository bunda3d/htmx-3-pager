✨Beautifully Simple: A Mini Stack Web App Demo

This "3-pager" proof-of-concept site demonstrates a lightweight web app with SPA-style navigation, forms interactivity, data persistence, and an admin dashboard—all on a minimal tech stack

Three-Pager?

A 3-page website includes the basic pages a small site needs: Home, About, and Contact. It emphasizes simplicity and maintainability, making it ideal for small projects.

What am I looking at here?

In this demo, HTML fragments load seamlessly into a responsive shared page with navbar, enabling smooth navigation and dynamic content updates without a full page reload. It demonstrates routed page navigation, a contact form, SQLite-backed record storage, an auth-gated admin dashboard; and requires no JavaScript build pipeline.

How is this simpler than established web app architectures?

Unlike JavaScript frontend frameworks (Angular, React, etc.) or full-stack frameworks (ASP.NET, Ruby on Rails, etc.), this approach avoids complex build tools, bundlers, and heavy middleware wiring. Edit page content as HTML; PHP handles server requests, and htmx swaps in responses. It produces a responsive Single Page Application (SPA) User eXperience (UX) from a dead-simple, maintainable architecture.

🛠️ Technology Stack

    ⚙️Backend

  • PHP → API / Data Access / Business Logic
  • SQLite → Data Store

    🖥️Frontend

  • HTML → Markup
  • CSS → Styling
  • JS → Client-side Interactivity

    📦Libraries

  • htmx → AJAX and DOM Manipulation
  • Bootstrap 5 → Responsive Design

🚀 Architectural Items

  • ✅ Fragment navigation: htmx requests HTML from PHP and replaces the page content without reloading the whole shell.
  • ✅ Contact requests: PHP handles form submissions and saves records to SQLite.
  • ✅ Responsive layout: Bootstrap provides the layout and navbar behavior.
  • ✅ No frontend build step: the page fragments can be edited as HTML; PHP serves the dynamic responses.
  • ✅ Maintainability & Portability: Most sites are WordPress, also built on PHP | JS | HTML | CSS. More web devs know the stack & most hosting plans can run the app.
  • ✅ Simplicity: a dead-simple file structure makes implementation easier.
